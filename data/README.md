# RENALIS - Data & Synthetic Generators

This directory contains synthetic dataset artifacts, generator scripts, and data ingestion pipelines.

## Planned Sources
- **Synthea Synthetic Patient Cohorts:** Demographics, conditions, encounters, and medication histories.
- **Custom Longitudinal CKD Generator:** Synthetic time-series generation for eGFR, serum creatinine, urine albumin-to-creatinine ratio (uACR), systolic/diastolic blood pressure, and HbA1c with realistic physiological noise and treatment effects.

## Synthetic Data Notice
> **IMPORTANT:** All datasets stored, referenced, or generated within this directory are strictly **100% synthetic**. No Protected Health Information (PHI) or real patient records are present or used.
