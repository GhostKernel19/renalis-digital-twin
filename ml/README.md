# RENALIS - Machine Learning

This directory contains the machine learning pipelines, training notebooks, and progression forecasting models for RENALIS.

## Planned Stack
- **Modeling & Evaluation:** scikit-learn, NumPy, pandas
- **Model Serialization:** Joblib

## Scope
- Longitudinal eGFR trajectory slope estimation and rapid decliner classification
- Kidney failure risk estimation (Kidney Failure Risk Equation / KFRE adaptation)
- Multi-variate feature extraction from synthetic longitudinal biomarker histories
