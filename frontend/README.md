# RENALIS - Frontend

This directory contains the user interface for the RENALIS Chronic Kidney Disease (CKD) Digital Twin & Care Coordination platform.

## Planned Stack
- **Framework:** React + TypeScript (scaffolded via Vite)
- **Visualization:** Recharts for longitudinal eGFR, uACR, and simulated trajectory charts
- **Styling:** Vanilla CSS design system

## Scope
- Patient twin profile and longitudinal timeline viewer
- Counterfactual intervention simulator (e.g., ACEi/ARB initiation, SGLT2i addition, blood pressure control targets)
- Nephrology care coordination and alert prioritization dashboard
