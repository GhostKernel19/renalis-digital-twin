# RENALIS - Documentation

This directory contains architectural specifications, clinical background references, challenge deliverables, and API documentation for the Digital Twin Challenge 2026.

- `/architecture`: High-level system design, data flow diagrams, and digital twin state model specs
- `/clinical-context`: KDIGO guidelines reference notes, CKD staging metrics (G1-G5, A1-A3), and synthetic parameter justifications
- `/challenge`: Submission deliverables, problem statements, and presentation assets
